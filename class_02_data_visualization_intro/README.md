# Class 02: Data Visualization Introduction & Chart Selection

## 📌 Overview
This session introduces core visualization principles using **Matplotlib** and **Seaborn**, focusing on selecting the right chart based on analytical questions rather than memorizing syntax.

## 🎯 Topics Covered
1. **Fundamentals of Matplotlib**: Anatomy of a plot (`Figure` vs `Axes`), Object-Oriented interface
2. **Chart Selection Framework**:
   - **Distribution**: Histogram, KDE, Boxplot (Bimodal distributions)
   - **Comparison**: Vertical, Horizontal, and Grouped Bar Charts
   - **Data Ethics**: The danger of truncated Y-axes
   - **Time Trend**: Line charts, multi-series tracking, event annotations
   - **Composition**: Stacked bar charts vs. Pie charts (Perception psychophysics)
   - **Relationship & Correlation**: Scatter plots with regression lines and correlation heatmaps
   - **Multiple Variables**: Pair plots (`sns.pairplot`)
   - **Geographic Patterns**: Ranked regional lollipop/bubble chart
