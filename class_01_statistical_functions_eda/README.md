# Class 01: Statistical Functions in Exploratory Data Analysis (EDA)

## 📌 Overview
This class covers essential summary and descriptive statistics using Python and Pandas to analyze real-world numerical and categorical distributions.

## 🎯 Topics Covered
- Statistical overview with `describe()`
- Measures of Central Tendency: Mean, Median, Mode (and when mean misleads)
- Measures of Dispersion: Variance and Standard Deviation
- Percentiles, Quartiles & Interquartile Range (IQR)
- Outlier detection via Tukey's $1.5 \times \text{IQR}$ rule
- Skewness and distribution shape (Right-skewed, Left-skewed, Symmetric)
- Multi-group comparisons using `groupby()` + `agg()`
- Relationships: Covariance vs. Pearson Correlation ($r$)
